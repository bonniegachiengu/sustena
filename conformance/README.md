# Conformance vectors

**The behavioural contract both Sustena engines must satisfy.**

A vector is a recorded fact: *given this starting state and this sequence of
operations, an engine must produce exactly this result.* The vectors are plain
JSON and belong to no language.

Two engines replay them:

| Engine | Replayed by |
|---|---|
| Python (reference, live today) | `apps/api/tests/test_conformance_vectors.py` |
| Rust (`sustena-core`) | `sustena-core/tests/conformance.rs` |

## Why this exists

The Rust core is a re-implementation of a working engine that a real household
depends on. Hand-porting 2,199 pytest cases would mean translating the tests as
well as the code — doubling the work and risking porting the *bugs* along with
the behaviour.

Instead the vectors are **generated by exercising the reference engine**, then
replayed against both. That gives three things:

1. **A real oracle.** The Rust port is measured against recorded behaviour, not
   against someone's reading of it.
2. **A regression net for Python.** The reference engine replays its own
   vectors, so a vector that stops matching means the reference changed.
3. **A durable spec artifact.** Any future implementation — another language, a
   rewrite — must pass the same file. The contract outlives both engines.

## Regenerating

```bash
cd apps/api
python ../../conformance/generate.py
```

Regeneration **records current behaviour**. It is not a way to make a failing
test pass: if a vector changes, that is a behavioural change and must be a
deliberate, reviewed one. Check the diff.

## What is compared

- **Resulting state** — exact, byte-for-byte.
- **Mutation records** — exact, including the legacy `action` key.
- **Per-operation results** — return values, and whether the operation failed.
- **Failure kind** — `path` vs `value` — exact.

**Not compared: exact error prose.** Both engines record their message and the
vectors carry both, but the assertion is on kind. Python's `repr()` and Rust's
formatting differ in ways that say nothing about behaviour, and pinning the
wording would make the contract about strings instead of semantics. Kind plus
which operation failed is the real observable.

## Layout

```
conformance/
  generate.py           regenerates every vector file from the reference engine
  vectors/
    state.json          the State primitive
    fold.json           state = fold(events)
```

`conformance_version` in each file guards the format. A stale vector set fails
loudly rather than silently passing against the wrong expectations.
