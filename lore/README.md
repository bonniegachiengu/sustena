# Lore
Sustena's public knowledge and narrative layer.
Manages: /blog, /arena, /docs, /q&a, /about, /contact, whitepaper, and all public-facing content.
DNS: lore.sustena | lore.dev

## Pages

**blog.html** — Public journal. Journal entries marked `public: true` surface here. The internal journal (journal.html) stays private to authenticated users.

**Arena.html** — The Mycelium public marketplace. Discoverable without login. Contains:
- Operatives, Operators, Sustain Spores, Widgets (developer-published packages)
- Real-world products: Vyyb menu items, Mkulima farmer produce, Biashara merchant listings
- Any sustain participant can list products; the network governs trust scoring
Arena is the public discovery layer; the in-app Library panel is the authenticated install/manage layer.

**docs.html** — The Sustena technical specification and whitepaper rendered in the Sustena design language. Content sourced from docs/Sustena_XII_Master_Strategy.md.

**Note on /journal vs /blog:** The internal journal (operational decisions, notes, reflections, sustain updates) is private and lives inside the authenticated control panel. The blog is a curated public surface — entries opt in via a `public` flag.
